# Digital Marketing Analytics Dashboard

## Project Overview
This project analyzes digital marketing campaign performance using BigQuery SQL and Power BI.

## Tools Used
- Google BigQuery
- SQL
- Microsoft Power BI
- DAX

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Ad Spend
- Impressions
- Clicks
- CTR (Click-Through Rate)
- CPC (Cost Per Click)
- Conversion Rate
- ROAS (Return on Ad Spend)
- CAC (Customer Acquisition Cost)

## Dashboard Features
- Campaign-wise revenue comparison
- Platform-wise performance comparison
- Campaign performance table
- Interactive platform and campaign filters

## Data
The project uses a four-record illustrative campaign dataset for Google Ads and Meta Ads. It is intended for learning and demonstration.

## Project Structure
- PowerBI: Power BI dashboard
- SQL: BigQuery SQL queries
- Screenshots: Dashboard screenshots
